# 质量检查规则

## `desktop-full` 脚本自动检查

- 图片可解码且为 PNG。
- 工作图尺寸为 `1152×2048`，最终图尺寸为 `1080×1920`。
- 输出无透明像素，四角背景为纯白。
- 黑白版和彩色版来自同一个已批准线稿层，并记录其 SHA-256。
- 原始输入、中间文件和恢复任务时使用的关键文件哈希一致。

## `web-light` 基础检查

- 仅检查 PNG 可解码、标准化工作尺寸、不透明输出和白色四角。
- 不覆盖不可变线稿层，不执行像素级线稿比较。
- 自动结论最多为 `LIGHT_PASS`；人工确认后最终记录 `HUMAN_REVIEW_ONLY`。

## Agent 视觉检查

在 `REVIEW_LINEART` 检查：

- 只保留目标人物，人物完整且没有裁切头发、手脚或服装。
- 没有对白框、气泡、文字、拟声词、其他人物或背景细节。
- 比例、姿势、五官、表情、发型、服装轮廓和线条粗细没有明显变化。
- 红色候选变化区中的补线只延续必要的局部轮廓；任何大面积重建都要求重做。

在 `REVIEW_QC` 检查：

- 角色发色、瞳色、肤色、服装和配饰颜色符合参考图或用户配色说明。
- 人物位置和轮廓与已批准线稿一致。
- 没有新增黑色轮廓、文字、人物、道具或背景装饰。
- 阴影和高光自然，不遮盖线稿；背景保持纯白。
- 没有多指、缺肢、变脸或服装结构改变。

语义检查失败时，用具体问题运行 `retry-clean` 或 `retry-color`。同一阶段最多重试两次，超过后停止并交由用户决定。
