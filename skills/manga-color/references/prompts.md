# 模型提示词契约

提示词正文由 `scripts/manga_color_lib/prompts.py` 维护。本文件说明修改提示词时必须保留的行为契约。

## 线稿清理

- 输入图是结构来源，任务是编辑而不是重画。
- 只保留目标人物的完整可见身体、头发、面部、服装、穿戴配饰和与身体直接相连的物件。
- 删除背景、其他人物、对白框、气泡、文字、拟声词、页码及书写元素。
- 保留全部可见人物线条，不改变比例、姿势、五官、表情、发型、服装轮廓和线条粗细。
- 文字遮挡人物时，只补齐局部轮廓连续性所需的最短线段；不推断大面积不可见结构。
- 输出为 `1152×2048`、9:16、纯白背景的黑白线稿，不添加元素。

## 参考图上色

- 第一张图是已批准的结构来源；后续图片只用于角色颜色和材质参考。
- 不复制参考图的姿势、表情、构图、背景、文字或光源方向。
- 只增加色彩、柔和阴影和高光，不改变人物位置和任何线条结构。
- 背景必须纯白，不添加人物、道具、文字或装饰。
- 明确要求尽量输出没有新增黑色轮廓的颜色底层，以便确定性覆盖原始线稿层。
- 没有参考图且用户明确允许推断时，必须写明已确认的角色及版本；不得静默切换服装或版本。

提示词不能替代人工线稿确认和本地线稿复合。
